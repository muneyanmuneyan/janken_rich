  # ①課題名
じゃんけんリッチ

## ②課題内容（どんな作品か）
- 好きな手を選んでコンピュータと対戦し、勝ち・負け・あいこをイラストで表示するじゃんけんゲームです。
- 1～3の乱数でコンピュータの手を決め、自分の手との組み合わせで勝敗を判定します。
- 「じゃん・けん・ぽん！」の掛け声に合わせて、自分の手とコンピュータの手を並べて表示します。
- 勝ち・負け・あいこの回数を数える戦績カウンターと、5回勝負モードがあります。5回終わると最終結果（優勝・引き分け）を表示し、リセットボタンで最初から遊べます。

## ⑤工夫した点・こだわった点
- タイトル、グー・チョキ・パーのボタン、勝ち・負け・あいこの結果をイラストにしました。ボタンは赤・黄・青に色分けし、タイトルの配色とそろえて統一感を出しました。
- `setTimeout` を使い、「じゃん」「けん」「ぽん！」の掛け声のあとにお互いの手、その後に結果が順番に表示されるようにしました。勝ち負けの判定はクリックした瞬間に済ませ、表示だけを遅らせています。
- 掛け声や最終結果は、CSSの `@keyframes` で「ポン」と飛び出すように表示しています。
- ボタンは、マウスを乗せると明るくなり、クリックすると沈み込むように動くので、押した手応えが伝わるようにしました。
- 背景は、CSSの `radial-gradient` で、薄いオレンジにドットを互い違いに並べた柄にしました。画像は使わず、CSSだけで作っています。
- 結果が表示されるまで次のクリックを受け付けないようにして、前の勝負の表示と混ざらないようにしました。
- 表示までの時間（`HAND_DELAY`・`RESULT_DELAY`）と勝負の回数（`MAX_ROUND`）をスクリプトの最初で定数にまとめ、値を1か所変えるだけで調整できるようにしました。

## ⑥難しかった点・次回トライしたいこと（又は機能）
- 【難しかった点】「好きな手を選んでね」とボタンの間が大きく空いてしまい、原因探しに苦労しました。テンプレートのCSSにあった `p { height: 200px; }` が原因でした。CSSは複数の指定が重なって効くので、どの指定が効いているのかを確認する大切さを学びました。
- 【難しかった点】グー・チョキ・パーの画像は、それぞれ透明な余白の量が違ったため、ボタンの中の位置をそろえるのが難しかったです。`flex` で中央にそろえたうえで、`transform` で1枚ずつ微調整しました。
- 【難しかった点】自分の手を表示する関数を別の関数の中に書いてしまい、表示されないことがありました。関数の中で作った関数は外から使えないこと、関数は作るだけでなく呼び出す必要があることを学びました。
- 【次回トライしたいこと】連勝記録、効果音、結果のイラストのアニメーションを追加したいです。
- 【次回トライしたいこと】グー・チョキ・パーで同じ形になっている3つのクリック処理を1つにまとめて、コードをすっきりさせたいです。
